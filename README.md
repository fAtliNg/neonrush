# Neon Rush

Ночная гонка в браузере: мокрый неоновый город, дождь, пять соперников и три круга по 2,8 км — через тоннель и по мостам над рекой.

Всё процедурное: город, машина, вывески, звук двигателя. Готовых моделей и текстур нет, сборка весит около 340 КБ в gzip.

## Стек

- React 19, TypeScript, Vite 7, CSS Modules
- three.js 0.186: `WebGPURenderer` (на браузерах без WebGPU откатывается на WebGL 2), шейдеры на TSL
- Web Audio для звука

## Что внутри

| Файл | Что делает |
|---|---|
| `src/game/track.ts` | Кольцо 2,8 км по сплайну, поиск ближайшей точки |
| `src/game/world.ts` | Асфальт с лужами и зеркальным отражением, тротуары, отбойники, здания с ярусами и техникой на крышах, вывески и щиты, фонари с объёмным светом, река с мостами, тоннель, арка старта |
| `src/game/car.ts` | Машина из лофта по сечениям: лак, стекло, диски, фары, подсветка днища, пламя нитро |
| `src/game/physics.ts` | Аркадная физика: передачи, занос с помощником, нитро, удары о стены |
| `src/game/effects.ts` | Дождь на GPU, брызги, дым, искры, подсветка машины ближайшими фонарями |
| `src/game/audio.ts` | Синтез двигателя, визга шин, ветра и дождя |
| `src/game/features.ts` | Где на трассе река, мосты, тоннель, разделители и порталы |
| `src/game/obstacles.ts` | Столбы: сносимые указатели и несносимые опоры, разделители — столкновения |
| `src/game/race.ts` | Участники, круги и места, ИИ ботов |
| `src/game/Game.ts` | Рендер, постобработка (bloom, motion blur, виньетка, зерно), камеры, заезд с отсчётом, столкновения машин |

## Запуск

Нужен Node 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Отладка: `?debug=nobloom,nomb,novol` отключает bloom, motion blur и объёмный свет.

## Управление

W/S — газ и тормоз, A/D — руль, пробел — ручник, Shift — нитро, C — камера, R — вернуть на трассу, M — звук, F — полный экран, Esc — пауза. Геймпад тоже поддерживается.
